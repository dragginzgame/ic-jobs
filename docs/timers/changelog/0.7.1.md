# 0.7.1 dependency maintenance

Status: released 0.7.1.

## Changes

- Update the exact workspace `ic0` pin and both lockfiles from 1.1.0 to 1.2.0.
- Upstream 1.2.0 adds `subnet_self_node_count` and `cost_http_request_v2`.
  Comparing the published sources shows no changes to existing bindings.
  Neither addition is used by this runtime, so no platform or public API
  changes are required. The provider remains exact `ic-cdk-timers` 1.0.0.
- The dependency retains Rust 1.88.0 as its minimum supported version.
- Update the nested testing workspace's exact `ic-cdk` pin and resolved
  `ic-cdk-macros` from 0.20.2 to 0.20.3. The CDK adds wrappers for the same two
  new system bindings; the macro source is unchanged. Neither canister probe
  requires source adaptation, and Rust 1.88 remains supported. This part of
  the update affects repository test tooling only.

This crate dependency update shipped on the `0.7.1` release line.
The public API and runtime behavior are unchanged. The validation below records
the targeted checks, without claiming an additional complete release-gate run.

## Validation

- All 94 native tests, warning-denied Clippy, root Wasm compilation, Rust
  1.88 workspace checking, and provider-boundary checks pass.
- Both nested canister probes compile for Wasm with Rust 1.88.
- With `ic-cdk` 0.20.3, `make testing-check` passes formatting and
  warning-denied Rust 1.88 Clippy for every supported nested probe
  configuration; both canister probes also pass Rust 1.88 Wasm checking.
- Both lockfiles pass locked offline metadata checks; the root dependency
  graph has no duplicate packages.
- PocketIC recovery and performance evidence was not rerun for this additive
  bindings update; the existing release evidence remains historical.
