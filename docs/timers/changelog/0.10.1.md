# 0.10.1 resolved schedule ownership

Status: released 0.10.1.

## One resolved schedule

The private schedule owner resolves deadlines, requested relative delays and
scheduling modes into one `ResolvedSchedule`. Explicit requests and ordinary
completion directives share that value with the registry's pending commands.
Stop resolves to no successor schedule.

The old registry `PendingSchedule` wrapper, separate `ResolvedDirective`,
completion conversion and private directive-snapshot mode mapping are deleted.
Completion no longer substitutes an earlier entry mode when forming a successor.
The public `TimerDirectiveSnapshot` conversion remains an inert projection with
its independent duration-range validation; no snapshot becomes control authority.

Earliest/exact selection, command precedence, request-time relative resolution,
observed modes and delays, typed failure handling, declaration lifetimes and
provider binding retain their existing behavior. This is a private simplification
suitable for a patch release; public API and snapshot shape are unchanged.
