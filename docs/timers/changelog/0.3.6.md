# 0.3.6 downstream truth and release-handoff hardening

Status: released 0.3.6.

## IcyDB adoption truth

- IcyDB 0.226.1 is tagged and adopted exact `ic-timers` 0.3.4.
- Its validated post-tag integration upgrades to exact 0.3.5 and replaces
  deadline-derived liveness with `WatchdogRegistration::has_armed_wakeup()`.
- Durable recovery demand continues to invoke `ensure_scheduled()`
  unconditionally, so the observation is not a check-then-arm control path.
- The maintained record captures the updated downstream Wasm measurement,
  unchanged instruction samples, dependency unification, and unchanged Candid
  and persisted-state boundaries. Landing that dirty downstream worktree
  remains IcyDB-owned.

## Release truth

- The compact status now describes 0.3.5 as released and opens the 0.3.6
  documentation-only patch line.
- Release-truth validation remains exact for Cargo, the dated changelog,
  release-note status, and compact-status version markers.
- Free-form status prose is deliberately not interpreted as a release blocker;
  the finalizer does not rewrite arbitrary narrative, so rejecting it after
  version mutation could strand an otherwise complete release bump.

## Runtime impact

No runtime, registry, provider, snapshot, or public API behavior changes.
