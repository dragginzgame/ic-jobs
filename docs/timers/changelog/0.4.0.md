# 0.4.0 cleanup and hard cuts

Status: released 0.4.0.

## Implemented scope

- Make the crate root the only public import facade; `schedule`, `snapshot`,
  runtime, registry, control, and platform modules are implementation details.
- Collapse the public `TimerLabel` layer into `TimerIdentity::try_new`, expose
  components as `&str`, and use one field-specific `TimerIdentityError`.
- Rename the public identity bound to
  `MAX_TIMER_IDENTITY_COMPONENT_BYTES`.
- Remove the inert-snapshot-to-command conversion and duplicate
  expected-failure-streak forwarding methods.
- Remove convenience projections that duplicate typed cadence, split provider
  counters, or top-level canonical snapshot fields.
- Prevent consumers from default-constructing partial observation fragments;
  their zero state is now private to the registry-owned constructor.
- Consolidate exact-claim lifecycle verification, ordinary scheduled
  transitions, earliest/exact deadline mutation, provider-role slot selection,
  and lazy provider-handle draining.
- Make platform and detached provider capabilities `must_use` inside the
  private ownership layer.
- Restore or clear every detached watchdog capability even when restoring the
  first of two provider handles fails.
- Restore all exact provider handles if an unexpected registry error occurs
  after a synchronous public operation has detached them; retire the claim if
  restoration cannot re-establish canonical ownership.
- Consolidate terminal watchdog failures through one transition that clears
  pending commands, and check both successor generations before mutating
  either counter.
- Keep illegal directive/policy pairing behind a private error boundary and
  remove the unreachable public `ScheduleError::MissingCadence` variant.
- Borrow claims in the private unregistration path and construct delegated
  callback claims from one exact callback token, removing redundant identity
  allocation and split authority inputs.
- Preserve the private exact `ic-cdk-timers` 1.0.0 boundary, canonical
  registry, lifecycle behavior, and proven two-message Watchdog protocol.

No compatibility aliases, deprecated forwarders, fallback registries, dual
state, or legacy feature paths are retained.

## Migration

- Move `ic_timers::schedule::*` and `ic_timers::snapshot::*` imports to the
  crate root.
- Replace `TimerLabel` construction and `TimerIdentity::new` with
  `TimerIdentity::try_new`.
- Remove `.as_str()` after identity component getters, which now return
  `&str` directly.
- Replace `MAX_TIMER_LABEL_BYTES` with
  `MAX_TIMER_IDENTITY_COMPONENT_BYTES` and match the new
  `TimerIdentityError` variants directly.
- Read failure streaks from `TimerOutcomeSnapshot` or the retained
  identity-scoped runtime query.
- Construct executable directives explicitly instead of converting an inert
  `TimerDirectiveSnapshot` back into a command.
- Replace `policy.cadence_ns()` with
  `policy.cadence().map(TimerCadence::as_nanos)`.
- Read `wakeups_armed` and `work_dispatched` separately. Add them explicitly
  only when an adapter genuinely needs a cross-role provider-arm total.
- Use `TimerSnapshot::scheduling_mode()` and
  `TimerSnapshot::next_deadline_ns()` instead of projecting those values from
  nested directive or runtime-state observations.
- Do not default-construct counters, performance summaries, outcomes, or
  observability fragments. Obtain coherent values from a registry snapshot.
- Remove any match arm for `ScheduleError::MissingCadence`. Public schedule
  requests never returned it; cadence-free recurrence remains a terminal
  internal directive/policy violation.

Maintained Canic and IcyDB sources already import from the crate root and use
`TimerIdentity::try_new`; the inspected Canic worktree has two mechanical
`.as_str()` removals. Requalify both consumers against one exact 0.4 package
only after this hard cut is released.

## Evidence

The normal local CI gate passes: action-pin and shell checks, release wiring
and truth, provider-boundary enforcement, formatting, workspace check,
warning-denied Clippy and rustdoc, all 78 native tests, Wasm compilation, and
offline package build/verification. Rust 1.88 compiles every workspace target,
and every supported nested runtime and size-probe configuration passes
warning-denied Clippy on Rust 1.88. The dependency tree has no duplicates, the
package contains the intended 18 files, both non-mutating 0.4 finalizer checks
pass, release impact is correctly classified as `crate`, and diff whitespace
validation passes.

Fresh generated rustdoc exposes only the crate-root facade; it contains no
public module entry or symbol for the removed paths. The remaining panic-like
source matches are confined to test fixtures and the test-only platform fake.

The additional fault tests prove both the two-handle restoration path and
restoration after an unexpected synchronous post-detach transition error.
Pure watchdog tests cover paired-generation, deadline, and request-sequence
terminal failures, including pending-command cleanup. PocketIC is not repeated
because normal timer transitions, provider calls, and the Watchdog
scheduler/work protocol are unchanged. The maintainer-owned release gate will
retain the full real-canister evidence requirement when the package version is
advanced.
